User Query: "investors in Delhi" ↓ [1] queryParser.js → { region: India, city: Delhi } ↓ [2] discovery.js + discovery-search.js → 25 sources (seed + DuckDuckGo) ↓ [3] crawler.js (static) + crawler-playwright.js (JS) → 208 raw HTML pages ↓ [4] extractor.js → 400 raw records ↓ [5] schema.js → 400 valid, 0 invalid ↓ [6] deduplicator.js → Union-Find → 70 unique groups ↓ [7] email-verifier.js → email verification ↓ [8] db.js → Supabase + crawl-results.json ↓ [9] Dashboard → 68 investors displayed

6. Layer 3: Crawling

📄 crawler.js — Static Site Crawler

Kya karta hai: Simple HTML sites ko axios + cheerio se crawl karta hai.

Full Flow:

async function crawlSite(startUrl, allRecords) {
  // 1. robots.txt check
  const robots = await getRobots(startUrl);
  if (!robots.isAllowed(startUrl)) return;

  // 2. Sitemap.xml parse
  const sitemapUrls = await getSitemapUrls(startUrl);
  // → /team, /portfolio, /about mile

  // 3. Queue setup
  const queue = [startUrl, ...sitemapUrls];
  const visited = new Set();

  // 4. Har URL pe jaake
  while (queue.length > 0 && visited.size < 60) {
    const url = queue.shift();
    await rateLimit(startDomain);  // 500ms delay

    const res = await axios.get(url);
    const $ = cheerio.load(res.data);
    const text = $("body").text();

    // Investor page?
    const score = getInvestorScore(url, text);

    if (score >= 2) {
      if (isTeamPage(url)) {
        extractMultipleInvestors($, url);
      } else if (isPortfolioPage(url)) {
        extractPortfolioCompanies($, url);
      } else {
        extractInvestorData($, url);
      }
    }

    // Internal links follow
    $("a").each((_, el) => {
      const abs = new URL($(el).attr("href"), url);
      if (abs.hostname === startDomain) queue.push(abs.href);
    });
  }
}

Rules:

  • Same domain only
  • robots.txt respected
  • 500ms rate limit per domain
  • Max 60 pages per site
  • Junk pages skipped (privacy, terms, careers)

8. Layer 5: Validation

📄 schema.js — Data Cleaning

Kya karta hai: Extracted data ko validate + clean karta hai.

Cleaning Rules:

function cleanRecord(raw) {
  const r = { ...raw };

  r.name = typeof r.name === "string" ? r.name : "";
  r.sectors = Array.isArray(r.sectors)
    ? r.sectors.filter(s => typeof s === "string")
    : [];
  r.emails = Array.isArray(r.emails)
    ? r.emails.filter(e => isValidEmail(e))
    : [];

  return r;
}

Rejection Rule:

Sirf reject karta hai agar source_url missing ho. Baaki sab clean karke rakh leta hai.

Pass rate: 99% — kyunki hum reject nahi karte, sirf clean karte hain.

9. Layer 6: Deduplication

📄 deduplicator.js — Union-Find Algorithm

Kya karta hai: Same person multiple pages se aaye → ek record banao.

Problem:

Page 1: Srikanth Velamakanni + LinkedIn URL Page 2: Srikanth Velamakanni + email Bina dedup ke: 2 alag records ❌ Dedup ke saath: 1 merged record ✅

5-Level Merge Keys:

  1. LinkedIn /in/ URL — strongest signal
  2. Verified email — pattern emails excluded
  3. Name + Company — "Srikanth" + "nasscom"
  4. Name + Domain — "Srikanth" + "nasscom.in"
  5. Firm + Domain — firm-level records

Union-Find Algorithm:

// Har record ke saare identifiers generate karo
Record 1 identifiers:
  li:linkedin.com/in/srikanth
  nd:srikanth velamakanni|nasscom.in

Record 2 identifiers:
  email:srikanth@nasscom.in
  nd:srikanth velamakanni|nasscom.in

Common: nd:srikanth velamakanni|nasscom.in
→ Same group → MERGE

Shared Email Filter:

const SHARED_EMAIL_LOCALS = [
  "info", "contact", "hello", "service", "newaccounts",
  "support", "sales", "admin", "team"
];

// Ye merge keys NAHI bante
// Warna 20 nasscom records 1 ho jayenge

Confidence Scoring:

Verified email      → +0.5
LinkedIn profile    → +0.3
Person name         → +0.1
Company name        → +0.1
Sectors             → +0.05
Fresh (2024+)       → +0.05

Total: 0.0 - 1.0

HIGH:       >= 0.5
MEDIUM:     < 0.5
QUARANTINE: < 0.4  (review queue)

async function saveInvestors(records) {
  // 1. Delete old records with same source_url
  await supabase.from("investors")
    .delete()
    .in("source_url", urls);

  // 2. Insert new records
  const { data } = await supabase.from("investors")
    .insert(cleaned);

  return { saved: data.length };
}

11. Background Jobs

📄 scheduler.js

Kya karta hai: Har 24 hours mein check karta hai — kya re-crawl karna hai.

Logic:

function startScheduler() {
  setInterval(() => {
    runScheduledCrawl();  // Every 24 hours
  }, 24 * 60 * 60 * 1000);
}

async function runScheduledCrawl() {
  const history = loadHistory();
  const now = Date.now();

  // 7 din se purani queries dhundo
  const rerun = history.filter(entry =>
    now - new Date(entry.timestamp).getTime() >= WEEK_MS
  );

  for (const entry of rerun) {
    await crawlUrls(entry.urls, entry.query);
  }
}
